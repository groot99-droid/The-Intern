# Reference Images

← [[blender/Blender Pipeline|Blender Pipeline]]

3 stills used as visual-matching reference while modeling the 3 pilot environments. Each is a byte-identical copy of the corresponding file in [[ninety-nine/assets/Generated Assets|ninety-nine/assets/img/]] — kept locally so they're available as reference images/planes inside the `.blend` without reaching across the project; left in place rather than deduplicated since the working file may load them by relative path.

- **`S1_C_IMG_IN.png`** — reference for the Waiting Room environment.
- **`S5_H_IMG_IN.png`** — reference for the Parking Garage environment.
- **`SE_ASSIM_IMG_IN.png`** — reference for the Boardroom (assimilation ending) environment.
