# Walk Mode

← [[ninety-nine/src/Source Code|Source Code]]

The third option beside every scene's two choices from S1 on: **WALK THE ROOM**. Unscored -- it never touches conformance, dissonance, friction or flags -- and it leaves the drone, bed and music running (C7). Built the way the museum walkthrough in the Earth_Worldbuild repo is built: no GLB, no Blender export; a JSON layout per room, procedural box geometry, world-tiled textures, first-person controls with axis-separated raycast collision. Then the game's own look on top: a third-resolution render target scaled up with nearest-neighbour sampling, no anti-aliasing, and canon C1 as a material rule (the building is textured, lit and shadowed; everything the company owns is flat-shaded low-poly with PS1 vertex snapping).

Canon, enforced in code: **C1** two-tier materials ([[ninety-nine/src/walk/materials.js|materials.js]]); **C2** the one shadow-casting light sits on the entrance side and aims at the core, so every shadow falls toward the core ([[ninety-nine/src/walk/room.js|room.js]]); **C3** rooms are closed on every side unless `open` names one, and then fog or glass closes it (asserted by `rooms.validate.js`); **C5**/**C6** figures are static boxes with low-poly hands; **C8** exactly one handless clock per built room (asserted).

- **[[ninety-nine/src/walk/launcher.js|launcher.js]]** — what router.js talks to. Looks up `S{n}_{C|H}` in `data/rooms.json`, dynamic-imports the rest on the first click (three.js is 1.3 MB; the cold start stays at Doc 4 §8.2's 2 s), pauses the video layer, toggles `body.walking` (which is what stops Escape from reading as the fire exit while the pointer is locked).
- **[[ninety-nine/src/walk/walk.js|walk.js]]** — renderer, camera, scene, loop, HUD (LEAVE THE ROOM + hint), footsteps via sfx.js's `footstep` cue, per-room surface-tinted.
- **[[ninety-nine/src/walk/room.js|room.js]]** — builds a room from a record: floor/ceiling/walls from `size`, extra `boxes` (pillars, water, ledges, barriers), `props`, lights, fog, spawn.
- **[[ninety-nine/src/walk/props.js|props.js]]** — the company's things: chair, desk, monitor, partition, door, glass doors, curtain, sign, badge reader, counter, dispenser, figure, car, elevator panel, shelf, cooler, box tower, package, mop sink, drain, pillar, fluoro, sodium, emblem, placard, slip, clock. Mirrors the archetypes in [[blender/prop_builders.py|blender/prop_builders.py]].
- **[[ninety-nine/src/walk/materials.js|materials.js]]** — canvas-drawn procedural textures (marble, plaster, concrete, carpet, cinderblock, linoleum, pool tile, water, cardboard, rust, grate, glass…) tiled in world units; the `lp_*` flat palette with the vertex-snap shader patch.
- **[[ninety-nine/src/walk/controls.js|controls.js]]** — WASD / arrows, pointer-lock or drag look, touch joystick + drag-look; ported from the museum's controls.js and touch.js.

Data and tools: [[ninety-nine/data/rooms.json|data/rooms.json]] is generated by [[ninety-nine/tools/build_rooms.py|tools/build_rooms.py]] (edit that, not the JSON). Preview any room without playing to it at `/test/rooms.html?room=S4_C` ([[ninety-nine/test/Tests|test/]]). three.js r160 is vendored at `ninety-nine/vendor/three/` (MIT, licence alongside).
