# Walk Mode

← [[ninety-nine/src/Source Code|Source Code]]

The set builder the stage draws every scene with, and the third option beside every scene's two choices from S1 on: **WALK THE ROOM**. Walking is unscored -- it never touches conformance, dissonance, friction or flags -- and it leaves the drone, bed and music running (C7). Built the way the museum walkthrough in the Earth_Worldbuild repo is built: a JSON record per set, procedural box geometry, world-tiled textures, first-person controls with axis-separated raycast collision; the company's props from the open-source catalog where `tools/build_rooms.py` placed one (`glb`), box builders otherwise. Then the game's own look on top, and canon C1 as a material rule: the building is textured (512 px colour + bump + roughness, trilinear/anisotropic), lit, shadowed (soft 2048 px shadow map) and finished by the stage's composite pass (ACES, vignette, film grain, dither); everything the company owns is flat-shaded low-poly with PS1 vertex snapping and no texture at all -- catalog models included (`src/stage/library.js` re-materials every clone).

Canon, enforced in code: **C1** two-tier materials ([[ninety-nine/src/walk/materials.js|materials.js]]); **C2** the one shadow-casting light sits on the entrance side and aims at the core, so every shadow falls toward the core ([[ninety-nine/src/walk/room.js|room.js]]); **C3** rooms are closed on every side unless `open` names one, and then fog or glass closes it (asserted by `rooms.validate.js`; the street, before the lobby doors, is the one set with a sky colour); **C5**/**C6** figures are static boxes with low-poly hands (an actor translates, never animates); **C8** exactly one handless clock per built room (asserted).

- **[[ninety-nine/src/walk/launcher.js|launcher.js]]** — what router.js talks to for WALK THE ROOM: asks the stage to switch its own camera to free walk over the set that is already up (no second renderer), toggles `body.walking` (which is what stops Escape from reading as the fire exit while the pointer is locked).
- **[[ninety-nine/src/walk/room.js|room.js]]** — builds a set from a record: floor/ceiling/walls from `size` (`noWalls` / `noCeiling` for the street), `skirt` / `cornice` bands on every closed wall, `beams`, extra `boxes` (pillars, water, ledges, barriers), `props` (named ones are addressable: the `terminal`, the `manager`), `actors` (a named prop with a `path` the stage drives), lights (`flicker` = a per-fixture sodium/fluorescent buzz, never in unison), fog, spawn; a curtain that `swing`s, hands that `reach`.
- **[[ninety-nine/src/walk/props.js|props.js]]** — the company's things: chair, desk, monitor (its screen tagged for MG-05 C's sheet), partition, door, glass doors, curtain, sign, badge reader, counter, dispenser, figure, car, elevator panel, shelf, cooler, box tower, package, mop sink, drain, pillar, fluoro and sodium fixtures with glow plates, pendant, wall plate, pipe run, emblem, placard, slip, clock; added for the 3D-only build: keyboard, hands, mug, lamp, building, lamp post, table, and `glb` (a library model, with a box `fallback`). Mirrors the archetypes in [[blender/prop_builders.py|blender/prop_builders.py]] and the port in `tools/higgsfield_scene.py`.
- **[[ninety-nine/src/walk/materials.js|materials.js]]** — canvas-drawn procedural textures (marble, plaster, concrete, painted concrete, carpet, cinderblock, linoleum, ceiling tile, pool tile, water, cardboard, rust, grate, asphalt, glass…): each slot draws a colour map, a height map and a roughness map, tiled in world units; the water drifts per frame. The `lp_*` flat palette with the vertex-snap shader patch (exported for library.js), plus `glow_*` additive fixture glows.
- **[[ninety-nine/src/walk/controls.js|controls.js]]** — WASD / arrows, pointer-lock or drag look, touch joystick + drag-look; ported from the museum's controls.js and touch.js.

Data and tools: [[ninety-nine/data/rooms.json|data/rooms.json]] is generated by [[ninety-nine/tools/build_rooms.py|tools/build_rooms.py]] (edit that, not the JSON). Play any shot of any set, or walk it, without playing to it at `/test/rooms.html?room=S4_C&shot=loop` / `?room=S5_H&walk=1` ([[ninety-nine/test/Tests|test/]]). three.js r160 is vendored at `ninety-nine/vendor/three/` (MIT, licence alongside).
